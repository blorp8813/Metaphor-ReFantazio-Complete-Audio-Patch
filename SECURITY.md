# Metaphor: ReFantazio Complete Audio Patch — Security Policy

This plugin runs inside the game process and loads through a DLL proxy, so installation sources and binary integrity matter.

For a suspected vulnerability, do not publish exploit details or private logs in a public issue. Contact the maintainer privately through the security-reporting mechanism enabled on the repository. Include the affected version, reproduction conditions, and a minimal redacted proof of concept. Do not attach game executables, saves, credentials, or personal paths.

Only the latest release candidate and latest stable release, when available, are intended to receive security fixes. Verify release ZIP checksums before installation. This community project provides no warranty and is not an official support channel for the game, Wine, CrossOver, or Steam.
